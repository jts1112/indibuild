Getting Started Tutorial

Key Features

  • Customizable Sections
    Each subsection of your portfolio is placed inside a "box" that you can resize, move, duplicate, or delete as needed.
  • Flexible Content
    Use the suggested section headers as a starting point. Feel free to organize or redesign your layout however you want.
  • Portfolio Type Display
    At the top of the page, the type of portfolio you're building (e.g., Artist Portfolio, Software Engineer Portfolio) is always visible, keeping you on track.
  • Easy Navigation
    Clicking "Home" to return back to the home page and "Options" to return to the selection page.
  • Media Upbloads
    Ability to upload websites,repositories,images,video into your portfolio.

Building Your Portfolio

Warning: your data can be inputed into the portfolio normaly but will differ from whats downloaded.
  1. Start with the Default Selected Layout
    Locate pre-labeled sections like "About Me", "Projects", and "Gallery".
  2. Customize Your Boxes
    • Drag: Move any box to rearrange your layout.
    • Resize: Adjust the size of the box to better fit your content.
    • Duplicate: Duplicate Sections to have more of the sections.
    • Delete: Remove any box you dont need.
  3. Add Content
    • Upload images, links, text, or code based on your desired portfolio type.
    • Each box is designed for a specific type of content. Make sure to use the right boxes for the best outcomes.
  4. Preview and Download
    • Preview you portfolio
    • When your ready, download your portfolio.
Tips
  • Think Modular: Each box can represent a project, skill, or accomplishment.
  • Mix and match: Don't feel confined by default section. Make it yours!
  • Save Frequently: Make sure to Save or download regularly so progress doesnt get lost.
